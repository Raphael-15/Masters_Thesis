# Thesis Model Project Structure

This directory contains the implementation-ready project layout for the thesis model. It is intentionally minimal and contains placeholder files and templates to be populated with real data and code.

Top-level layout (this folder):

- data/: raw, processed and outputs
- config/: scenario register (baseline and sensitivity templates)
- src/: code packages (preprocessing, simulation, settlement, economics, validation, reporting)
- tests/: unit & integration tests
- thesis_context/: canonical LaTeX context (read-only reference)
- results/: generated tables, figures, and summaries

Populate the data/raw/ subdirectories with the source data files described in the IMPLEMENTATION_PLAN.md and in the LaTeX chapters.
